# Local Barber

Landing page para uma barbearia, desenvolvida com foco em design, responsividade e experiência do usuário.

O projeto simula a presença digital de uma barbearia, apresentando seus serviços, história, galeria de imagens, localização e uma chamada para agendamento.

## Funcionalidades

- **Página inicial:** apresentação da barbearia.
- **Serviços:** exibição dos serviços oferecidos.
- **Sobre:** seção para apresentar a história e os diferenciais do estabelecimento.
- **Galeria:** espaço para exibir imagens da barbearia e dos cortes.
- **Localização:** seção com informações sobre onde o estabelecimento está localizado.
- **Agendamento:** chamada para ação que direciona o cliente ao agendamento.
- **Layout responsivo:** adaptação da interface para dispositivos móveis e desktops.

## Tecnologias

- HTML5
- CSS3

## Responsividade

O layout foi desenvolvido para oferecer uma experiência de navegação em diferentes tamanhos de tela, incluindo computadores e dispositivos móveis.

## Objetivo

Este projeto foi criado para praticar desenvolvimento front-end e compor meu portfólio, demonstrando habilidades na construção de landing pages para pequenos negócios.
